# Class Craft Ghana — Next.js website

A responsive one-page marketing website recreated from the supplied design reference.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure
- `app/page.tsx` — page content, sections and form interactions
- `app/globals.css` — responsive styling
- `public/images/` — image crops derived from the supplied screenshot
- `app/layout.tsx` — metadata and root layout

The quote form is currently a front-end interaction. Connect it to WhatsApp, an email service, or your backend API before production.
